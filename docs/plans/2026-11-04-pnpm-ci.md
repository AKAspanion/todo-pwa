> **For agentic workers:** REQUIRED SUB-SKILL: the project's workflow policy names the executor (`run.executor`): ga:implement-with-subagents by default, or ga:implement. Follow the policy and this plan's Checkpoints. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** complete

**Goal:** Every job in `ci.yml` and `deploy.yml` installs and runs with pnpm, and the shipped-dependency audit passes again because the security overrides move to pnpm's own config.

**Architecture:** Task 1 moves the npm `overrides` from both `package.json` files into the matching `pnpm-workspace.yaml` and regenerates both lockfiles, so `pnpm audit` is clean. **Tech Stack:** pnpm `12.16.1` (`packageManager` in `package.json`), with `functions/` as a separate pnpm workspace root; GitHub Actions (`.github/workflows/ci.yml`, `deploy.yml`) with every action pinned to a commit SHA; Node from `.nvmrc`.
